# Arcium — EARN Campaign
A social media design created for an EARN campaign focused on on-chain privacy and Stealf wallets.

## Overview
The design explains why crypto wallet activity is public on-chain and introduces the concept of separating assets from everyday spending.

## Design Approach
The goal was to make a technical Web3 concept easier to understand through a visual, social-media-friendly layout.
The design uses:
- A dark Web3-inspired visual style
- Orange as the primary accent
- Short, easy-to-scan sections
- Icons and illustrations to explain concepts visually
- Clear separation between information and the Stealth wallet solution
